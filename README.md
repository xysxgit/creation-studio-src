# 🪄 创作助手 v2.33 · 从设定到 IP 的全链路创作工具

一个**画板式剧本创作工具**：把 Word 的排版能力、思维导图的直观和便签墙的自由，合到同一块无限画布上。支持小说、轻小说、RPG 游戏剧本、Galgame 脚本、影视脚本，以及局域网多人实时共创。

## 🚀 快速开始

**环境要求**：Node.js 18+、npm；如需构建安卓 APK，请额外准备 Android SDK（本仓库已配置 `/opt/android-sdk` 与 aapt2 兼容方案）。

```bash
npm install        # 安装依赖
npm run dev        # 浏览器开发模式 http://localhost:5173
npm start          # 构建前端并启动局域网服务器 http://localhost:8787
```

## ✨ 核心特性

### 画板式自由排版
- **任意摆放**：卡片像便签/积木一样在画布上自由拖动，大小随意缩放（拖四角手柄）
- **图片贴板**：图片可以独立成卡（拖入文件、任意缩放、铺满/完整显示），也能插进正文（粘贴、上传、调宽度）
- **富文本正文**（双击卡片进入）：标题、加粗、列表、表格、引用、代码块、文字颜色、荧光笔、链接、图片，排版能力接近 Word
- **无限画布**：空格+拖拽平移，Ctrl+滚轮缩放，迷你地图一键跳转，双击空白新建便签

### 思维导图式连线
- 选中卡片后，拖动卡片边缘的 **● 锚点** 到另一张卡片即可连线
- **拖动连线中段的小圆点**：拉出分支节点，可选手角色/事件/道具等模板创建，自动接上两端；拖到已有卡片则自动重连
- 连线右键/长按：**断开连线**、加注释、改虚线/箭头（单向/双向/无）/颜色
- 一键 **🌳 脑图布局** / **🕸 径向布局** / **▦ 网格整理**，自动按连线整理成思维导图
- 右键任意卡片可「以此卡为根做脑图布局」；卡片可切换 **🧠 导图节点模式**（紧凑节点样式）

### 项目管理
- 顶栏 **🗂 项目菜单**：新建项目 / 打开项目 / 项目设置 / 关闭项目（回欢迎页）/ 删除项目
- **⚙️ 项目设置**：查看与修改项目名称、类型、创建时间、页面/分区/卡片/连线统计，并可管理项目

### 编辑体验
- **双击卡片统一进入类 Word 的全屏编辑界面**（不再使用卡片内小编辑框），Escape 随时关闭
- **双击空白新建卡片**后不会误入编辑（浏览器 dblclick 落到新卡上会被抑制）
- 一个项目可拥有 **多个页面**（顶栏 📄 页面切换器）：每页独立卡片/连线/画笔标注，适合按幕、按卷、按地图区域分页创作
- 页面支持新建 / 切换 / 重命名 / 删除（数据随项目持久化）

### 项目文件夹分组
- 「打开项目」里可 **＋ 新建文件夹**，把项目拖入文件夹分组管理，随时移动/重命名/删除文件夹

### 保存 / 自动保存 / 云盘同步
- 顶栏 **💾 保存**（或 Ctrl+S）手动保存，并实时显示「已保存 / 保存中」状态；每次修改自动落盘（可在设置中关闭自动保存，关闭后页面关闭前仍强制保存，防止丢失）
- **☁️ 云盘同步（WebDAV）**：设置里填入坚果云 / Nextcloud / Box 等主流云盘的 WebDAV 地址与授权码，项目自动备份为 JSON 文件到云盘，支持「立即同步 / 从云端恢复 / 定时自动同步」；同步经局域网服务器转发绕过浏览器 CORS 限制

### 创作分区模板
内置分区：🌍 世界观 · 📋 大纲 · 📖 章纲 · ⭐ 重要角色 · 👤 次要角色 · ⚡ 事件 · 🎯 任务 · 🎒 道具 · ⚔️ 装备 · ✨ 技能 · 📈 等级 · 🗺️ 地图 · 🕳️ 伏笔 · 🌿 分支 · 🎬 场景 · 💬 对白 · 📝 便签
- 按项目类型（小说/RPG/Gal/影视/自由）自动配好常用分区，可随时增删改
- 右侧「灵感 → 模板」提供 16+ 种带字段的模板卡（重要角色卡、世界观设定卡、章节卡、等级表、选项分支卡……）一键插入
- 新建项目时可选择**附带完整样例项目**（雾城信使/灰烬王座/夏日纪念册/深夜电台），直接当参考或改着玩

### 画笔标注（完善版）
- 🖊 画笔 / 🧽 **橡皮擦**两个独立工具按钮（红色系样式区分）：画笔带 8 色色板 + 粗细滑杆 + 一键清空 + 删除选中标注；**橡皮模式自动隐藏颜色/粗细**，只显示擦除提示与操作
- 橡皮擦为**真擦除**：涂抹经过的笔画会被切分成多段（擦掉中间、两头保留），点选整条删除
- 笔画自动**平滑**（中点贝塞尔曲线）、抽稀降噪；轻点可画圆点

  - **智能体预设**：全能创作顾问 / 世界观架构师 / 角色塑造师 / 大纲与剧情策划 / 文风润色师 / 对白编剧 / 编辑校对 / 头脑风暴 / RPG 任务数值 / Galgame 分支 / 影视分镜 / 翻译官，共 12 个预设角色，各自带专属快捷指令

## 📱 安卓手机

### 方式一：PWA（推荐，免安装）
手机浏览器打开电脑的局域网地址 `http://<电脑IP>:8787`，菜单里选择「添加到主屏幕」即可像 App 一样使用。

### 方式二：安装 APK
- 电脑启动 `npm start` 后，手机访问 `http://<电脑IP>:8787/apk/`（页面上有二维码，扫码直达）
- 下载 `creation-studio.apk` 安装（需允许「安装未知来源应用」）
- 手机与电脑连**同一 Wi-Fi**，在应用内点「🌐 协同」→ 填 `http://<电脑IP>:8787` 即可实时共创

#### 获取局域网下载地址

运行以下命令即可打印本机可用的下载直链：

```bash
npm run lan
```

输出示例：

```text
局域网主页：    http://192.168.1.100:8787
安卓 APK 直链：http://192.168.1.100:8787/apk/creation-studio.apk
安卓下载页：    http://192.168.1.100:8787/apk/
```

服务器启动时也会自动打印这些地址。

#### 自行构建 APK

```bash
npm run android:apk
```

该命令会依次执行：

1. `npm run build` —— 构建前端到 `dist/`
2. `npx cap sync android` —— 同步 Web 资源到 Android 工程
3. `./gradlew assembleDebug` —— 编译 Debug APK
4. 复制成品到 `apk-dist/creation-studio.apk`

也可以手动构建：

```bash
cd android
./gradlew assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

> Android 工程已启用硬件加速、大堆内存、键盘调整和 Release 混淆/资源压缩；构建缓存与多余旧包已清理。
> 本仓库在 Linux aarch64 上通过 QEMU 包装的 aapt2 构建（见 `android/gradle.properties` 的 `android.aapt2FromMavenOverride`，依赖 `/opt/aapt2-x86/` 目录）。

## ❓ 常见问题

- **手机无法访问电脑的局域网地址？**  
  确认手机和电脑连接同一 Wi-Fi，关闭电脑防火墙或放行 `8787` 端口；也可用 `npm start` 启动时打印的其他局域网 IP。
- **APK 安装时提示“未知来源”？**  
  在手机设置中允许安装未知来源应用；APK 为 Debug 签名，仅用于测试/内部分发。
- **WebDAV 云盘同步失败？**  
  本项目通过局域网服务器转发请求绕过浏览器 CORS，请先保持 `npm start` 服务运行，并确认 WebDAV 地址、账号、授权码正确。
- **想使用本地 AI 模型？**  
  在设置中选择「Ollama 本地 / LM Studio 本地」，填写 `http://localhost:11434` 或对应局域网地址即可。
- **误删项目能恢复吗？**
