📲 怎么安装
  1. 1手机与电脑连接同一 Wi-Fi，电脑端保持本页面服务运行（npm start）。
  2. 2用手机扫码或直接点击上方「下载安卓版 APK」。
  3. 3打开下载的 APK，按系统提示允许「安装未知来源应用」。
  4. 4安装完成后打开即可使用，可选择 PWA 或 APK 两种方式。
🌐 局域网协同
  1. 1电脑端启动服务器：npm start，记下打印的局域网地址。
  2. 2手机打开应用 → 「🌐 协同」→ 填地址（http://电脑IP:8787）→ 上传并连接。
  3. 3其他人浏览器访问该地址，「打开项目 → 从局域网服务器打开」选择同一项目。
